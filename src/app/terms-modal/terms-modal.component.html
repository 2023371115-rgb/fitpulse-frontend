FitPulse Health Lab

Terminos y uso

Uso de la aplicacion

FitPulse Health Lab es un prototipo academico para registrar actividad fisica, metas, sesiones de entrenamiento y datos de demostracion relacionados con salud.

Datos de salud

Las metricas como pasos, frecuencia cardiaca, SpO2 o temperatura pueden provenir de datos demo, registros manuales o servicios simulados. No deben usarse para diagnostico medico ni para tomar decisiones clinicas.

Cuenta y seguridad

El acceso web usa autenticacion con token de sesion. La app Wear OS puede usar PIN local y biometria opcional para proteger el dashboard del reloj. El usuario es responsable de cerrar sesion en dispositivos compartidos.

Wearables y Smart TV

La integracion con wearable y Smart TV funciona como demostracion tecnica: el sitio puede sincronizar estado hacia el panel TV y el reloj puede mostrar datos desde backend o modo demo cuando no hay conexion.

Privacidad

La informacion registrada se usa dentro del proyecto para mostrar perfiles, metas, sesiones y paneles de actividad. No se debe capturar informacion sensible de terceros sin autorizacion.

Limitaciones

Este proyecto no reemplaza dispositivos medicos, servicios clinicos ni plataformas profesionales de monitoreo. Algunas funciones pueden depender de conexion local, base de datos, emuladores o servicios en desarrollo.
